# detect_hanzi

日本語テキストに混ざった中国語の漢字（主に簡体字）を検出するコマンドラインツールです。
中国製 AI などが出力した日本語文章に、「设定」「优秀」「天气」のような簡体字が紛れ込んでいないかをチェックできます。

## 特徴

- Python 3.9 以上の標準ライブラリだけで動作します（追加インストールは不要です）
- ファイルとフォルダを指定できます（フォルダは再帰的に検査します）
- 入力ファイルの文字コード（UTF-8／UTF-8 BOM付き／Shift_JIS／EUC-JP／UTF-16）を自動判定します
- 行・桁・コードポイントを出力し、前後の文脈も表示できます
- 終了コードで検出結果を返すため、CI やバッチ処理に組み込めます
- Windows では付属の `detect_hanzi.bat`、Mac では `detect_hanzi.command` をダブルクリックするだけで使えます（Windows ではファイルを `detect_hanzi.bat` にドラッグ＆ドロップしても使えます）

## 判定方法

Unicode では日本語と中国語の漢字が同じ「CJK統合漢字」として登録されているため、文字コードだけでは区別できません。
このツールは次の方法で判定します。

1. **日本の文字コードにない漢字を検出する**
   Shift_JIS（CP932：JIS X 0208 と NEC/IBM 拡張文字）で表せない漢字を「中国語の漢字」とみなします。
   例：们・说・这・设・优・钱・马・门・东・车・么
2. **追加リストの文字を検出する**
   Shift_JIS に収録されていても日本語ではまず使われない簡体字を追加で検出します。
   既定値：`个 气 儿 无 坏 听 苹`

### 制限事項

- 「学」「会」「来」「国」など、**日本の新字体と同じ形の簡体字は検出できません**（原理的に区別できません）。
- 日本語のまれな漢字（JIS 第3・第4水準の字など）が検出されることがあります。その場合は `--level jis2004` を使うか、`--allow` で除外してください。

## はじめての方へ（インストールから実行まで）

このツールは **Python**（パイソン）というプログラミング言語で作られています。
使うには、パソコンに Python を入れておく必要があります。プログラミングの知識は不要です。
以下の手順は、最初の 1 回だけ行えば大丈夫です。

### 手順 1：Python をインストールする

#### Windows の場合

1. Python の公式サイト https://www.python.org/downloads/ を開きます。
2. 黄色の「**Download Python 3.x.x**」ボタンをクリックして、インストーラーをダウンロードします。
3. ダウンロードしたファイル（`python-3.x.x-amd64.exe` など）をダブルクリックして起動します。
4. 最初の画面の下にある「**Add python.exe to PATH**」に**必ずチェックを入れて**から、「**Install Now**」をクリックします。
   - このチェックを忘れると、あとでコマンドが動きません。忘れた場合は、もう一度インストーラーを起動して入れ直してください。
5. 「Setup was successful」と表示されたら「Close」をクリックして完了です。

> Microsoft Store で「Python」と検索してインストールする方法もあります。

#### Mac の場合

1. https://www.python.org/downloads/ を開き、「**Download Python 3.x.x**」をクリックします。
2. ダウンロードした `.pkg` ファイルを開き、画面の指示に従ってインストールします。

#### インストールできたか確認する

1. ターミナルを開きます。
   - **Windows**：スタートメニューで「`cmd`」または「`ターミナル`」と入力して起動します。
   - **Mac**：Launchpad の「その他」にある「ターミナル」を起動します。
2. 次のコマンドを入力して Enter キーを押します。

   ```
   python --version
   ```

3. `Python 3.12.0` のようにバージョンが表示されれば成功です（数字は異なっていてかまいません）。

> **うまくいかない場合**
> - Windows で Microsoft Store が開いたり「見つかりません」と表示されたりする場合は、`python` の代わりに `py` と入力してみてください（例：`py --version`）。`py` で動いた場合は、このあとの説明の `python` もすべて `py` に読み替えてください。
> - Mac では `python` の代わりに `python3` と入力してください。このあとの説明も同じように読み替えてください。

### 手順 2：このツールをダウンロードする

1. https://github.com/Crytus/detect_hanzi を開きます。
2. 緑色の「**<> Code**」ボタンをクリックし、「**Download ZIP**」を選びます。
3. ダウンロードした `detect_hanzi-main.zip` を右クリックし、「**すべて展開**」（Mac ではダブルクリック）で展開します。
4. 展開してできた `detect_hanzi-main` フォルダを、わかりやすい場所（デスクトップや `ドキュメント` など）に置きます。

### 手順 3：ツールを実行する

#### Windows の場合（いちばん簡単な方法）

`detect_hanzi-main` フォルダの中にある **`detect_hanzi.bat`** を使います。

- **方法 A：調べたいファイルを `detect_hanzi.bat` にドラッグ＆ドロップする**
  黒い画面が開いて、すぐに検査結果が表示されます。複数のファイルやフォルダをまとめてドロップすることもできます。
- **方法 B：`detect_hanzi.bat` をダブルクリックする**
  黒い画面に「調べたいファイルまたはフォルダを、この画面にドラッグ＆ドロップして…」と表示されます。
  調べたいファイルを**黒い画面の上に**ドラッグ＆ドロップし、Enter キーを押してください。

どちらの方法でも、検査が終わると次のファイルの入力待ちになるので、続けて何回でも検査できます。
終わるときは、何も入力せずに Enter キーを押すか、画面右上の × で閉じてください。

> - まずは付属の `samples` フォルダを `detect_hanzi.bat` にドロップして、簡体字（「优」「设」「气」）が検出されるか試してみてください。
> - ダブルクリックしたときに「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」→「実行」をクリックしてください。
> - 「Python が見つかりません」と表示された場合は、手順 1 をやり直してください。

#### Mac の場合（いちばん簡単な方法）

`detect_hanzi-main` フォルダの中にある **`detect_hanzi.command`** をダブルクリックします。

1. ターミナル（文字だけの画面）が開き、「調べたいファイルまたはフォルダを、この画面にドラッグ＆ドロップして…」と表示されます。
2. 調べたいファイルやフォルダを**ターミナルの画面の上に**ドラッグ＆ドロップし、Enter キーを押すと検査が始まります。
3. 検査が終わると次の入力待ちになるので、続けて何回でも検査できます。
   終わるときは、何も入力せずに Enter キーを押してから、ターミナルを閉じてください。

> - Mac では、`detect_hanzi.command` のアイコンにファイルをドロップしても検査できません。必ず**ダブルクリックしてから、開いた画面にドロップ**してください。
> - **初めて開くとき**に「“detect_hanzi.command”は開いていません」「開発元を検証できません」などと表示された場合は、次のようにしてください。
>   1. 表示されたメッセージを「完了」または「OK」で閉じます。
>   2. Apple メニュー →「**システム設定**」→「**プライバシーとセキュリティ**」を開きます。
>   3. 下の方にある「“detect_hanzi.command”は…ブロックされました」の横の「**このまま開く**」をクリックし、パスワードを入力します。
>   4. もう一度 `detect_hanzi.command` をダブルクリックし、「開く」をクリックします。
>
>   （macOS 14 以前では、`detect_hanzi.command` を右クリック（control + クリック）して「開く」を選ぶ方法でも開けます）
> - 「適切なアクセス権がないため実行できません」と表示された場合は、ターミナルで `chmod +x ` と入力し（最後に半角スペースを入れます）、`detect_hanzi.command` をターミナルにドラッグ＆ドロップしてから Enter キーを押してください。そのあと、もう一度ダブルクリックしてください。
> - 「Python が見つかりません」と表示された場合は、手順 1 をやり直してください。

#### コマンドで実行する場合（Windows・Mac 共通）

1. `detect_hanzi-main` フォルダの中でターミナルを開きます。
   - **Windows 11**：フォルダを開き、何もないところを右クリックして「**ターミナルで開く**」を選びます。
     （または、エクスプローラーのアドレスバーに `cmd` と入力して Enter キーを押します）
   - **Mac**：Finder でフォルダを右クリックし、「**サービス**」→「**フォルダに新規ターミナル**」を選びます。
2. まず、付属のサンプルで動くか試します。次のコマンドを入力して Enter キーを押してください。

   ```
   python detect_hanzi.py samples -c
   ```

   簡体字（「优」「设」「气」）が検出されれば準備完了です。
3. 調べたいファイルを検査します。`python detect_hanzi.py -c ` まで入力したら（最後に半角スペースを入れます）、
   調べたいファイルやフォルダを**ターミナルの画面にドラッグ＆ドロップ**してください。場所が自動で入力されます。
   そのまま Enter キーを押すと検査が始まります。

   ```
   python detect_hanzi.py -c "C:\Users\あなたの名前\Documents\AIの出力.txt"
   ```

   `python detect_hanzi.py -c -i` と入力すると、バッチファイルと同じように入力待ちの状態で起動します。

#### 結果の見方

- `ファイル名:行:桁` の位置に、簡体字が見つかったことを表します（例：`3:7` は 3 行目の 7 文字目）。
- `【】` の中の文字が、検出された簡体字です。
- 最後の行が「`検出数: 0文字`」なら、簡体字は見つかりませんでした。

## 使い方

```
python detect_hanzi.py ファイルまたはフォルダ [...] [オプション]
```

> オプションは、ファイルやフォルダの前にも後ろにも書けます。

### 実行例

```
> python detect_hanzi.py samples -c
samples\sample.txt:1:10  '优' (U+4F18)  …このモデルは非常に【优】秀です。…
samples\sample.txt:2:1   '设' (U+8BBE)  …【设】定を変更してください…
samples\sample.txt:3:7   '气' (U+6C14)  …今日は良い天【气】ですね。…
--- 検出数: 3文字（種類: 3、ファイル: 1）
    优×1 气×1 设×1
```

出力形式：`ファイル名:行:桁<TAB>'文字' (コードポイント)<TAB>文脈`

### オプション

| オプション | 説明 |
|---|---|
| `-c`, `--context` | 検出した文字の前後の文脈を表示します |
| `-s`, `--summary-only` | 位置は出さず、文字ごとの集計だけを表示します |
| `-i`, `--interactive` | 対話モードで起動します。検査するファイルやフォルダの入力を繰り返し受け付け、空行で終了します。ファイルやフォルダも指定した場合は、それを先に検査します |
| `--level {cp932,jis2004}` | 判定に使う文字集合を指定します（既定：`cp932`）。`jis2004` は JIS X 0213（第3・第4水準）の漢字も日本語として扱います。誤検出は減りますが、「么」などの一部の簡体字を見逃します |
| `--allow 文字` | 指定した文字を検出しません（例：`--allow 们说`） |
| `--extra 文字` | 追加で検出する文字を指定します（既定：`个气儿无坏听苹`）。空文字（`--extra ""`）を指定すると追加リストを使いません |
| `--encoding 文字コード` | 入力ファイルの文字コードを指定します（既定：`auto` で自動判定） |
| `--ext 拡張子` | フォルダを指定したときに対象にする拡張子をカンマ区切りで指定します。空文字を指定すると全ファイルが対象になります。既定値は `.txt,.md,.csv,.json,.html,.htm,.xml,.srt,.vtt` です |

ファイルを直接指定した場合は、拡張子に関係なく検査します。

### 終了コード

| コード | 意味 |
|---|---|
| 0 | 検出なし |
| 1 | 中国語の漢字を検出 |
| 2 | 読み込みエラーあり |

対話モード（`-i`）で起動した場合、終了コードは常に 0 です。
